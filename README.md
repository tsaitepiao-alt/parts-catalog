# 零件庫 · 電子元件目錄

真實商品照的電子元件目錄，含場景需求排序（例：藍芽喇叭 → 前 3 套組合）與自動生成的組裝排線圖／零件爆炸圖。

## 圖片來源

本站所有零件照片為 **LCSC 商品頁的原始商品照**（保留原廠浮水印，未經修改或重繪），
每個零件頁面都附該料號的 LCSC 原始連結。若你是圖片權利人並希望下架，請開 issue。

## 資料來源

- 零件規格／價格／庫存：LCSC 商品詳情 API（抓取當下快照）
- 價格為美元單價，實際下單前請以 LCSC 頁面為準

## 建置

```
tools/scrape.py   抓零件資料與真圖
tools/build.py    產生 site/（含 SVG 組裝圖）
```
